# Google Search Console (GSC)

This page documents how we use Google Search Console for Donna CRM.

## Use the right property

- Prefer the **Domain property** (`donnacrm.com`).
- When submitting sitemaps and inspecting URLs, always use canonical host URLs:
  - `https://www.donnacrm.com/...`

## Sitemaps

- Submit: `https://www.donnacrm.com/sitemap.xml`
- Re-submit after adding new routes/pages to the site.

## Indexing workflow

1. Inspect one URL (canonical `www` version).
2. Click **Test live URL**.
3. Click **Request indexing**.

Do this first for your top 5–10 pages, not every page.

## Performance workflow (non-brand growth)

To see whether you’re ranking beyond “Donna CRM”:

- Go to **Performance → Search results**
- Add filter: **Query does not contain** `donna`
- That list tells you what Google is already testing you for (and where to create better pages).
